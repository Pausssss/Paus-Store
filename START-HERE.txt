PAUS STORE — STUDIO 6

1. Cài Node.js (18 trở lên).
2. Mở terminal tại thư mục chứa package.json.
3. Chạy: npm run dev
4. Mở: http://localhost:3000

Không cần npm install để chạy storefront.
Windows: có thể mở tools/run-local.cmd.

Kiểm tra: npm test
Build: npm run build
Thư mục triển khai: dist/

Hướng dẫn: README.md
Chỉnh nội dung: docs/EDIT-GUIDE.md
Kết nối nhận đơn: docs/SETUP-SUPABASE.md
Phạm vi kiểm tra: docs/QA-REPORT.md

21 kiểm thử logic và kiểm tra tĩnh đã đạt. Chưa QA trực tiếp bằng trình duyệt.
Khi backend chưa sẵn sàng, checkout chỉ tạo bản nháp để bạn tự gửi qua Zalo.
